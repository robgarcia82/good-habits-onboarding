# Zica — Onboarding de bons hábitos

Protótipo navegável de um onboarding para um aplicativo voltado a pais e crianças, com foco na criação de bons hábitos em família.

## O que está incluído

- seleção de até três áreas prioritárias;
- perfil básico da criança;
- diagnóstico rápido com sliders;
- seleção livre de motivadores positivos;
- geração de uma primeira rotina;
- planos mensal, trimestral e anual;
- teste gratuito por sete dias;
- transições e microanimações;
- apresentação em formato de celular e layout responsivo.

## Executar localmente

```bash
pnpm install
pnpm dev
```

Depois, acesse `http://localhost:5173`.

## Gerar a versão de produção

```bash
pnpm build
```

Os preços e conteúdos utilizados são demonstrativos e podem ser alterados em `src/main.jsx`.
